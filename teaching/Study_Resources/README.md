# Study_Resources

A course-neutral home for interactive biology study resources.

## Site structure

- `index.html` — main landing page
- `Bio100/` — BIO 100 course page and activities
- `Bio106/` — BIO 106 course page and activities
- `shared/styles.css` — shared site styling

## Publish with GitHub Pages

1. Open the repository's **Settings**.
2. Select **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Choose branch `main` and folder `/ (root)`.
5. Save. GitHub Pages will publish the site at `https://aemelton.github.io/Study_Resources/`.

## Adding an activity

1. Put the activity's HTML file in the appropriate course's `activities/` folder.
2. Add a link to that file in the corresponding course `index.html`.
3. Commit and push the changes to `main`.

## Taxa Matching

The BIO 106 Taxa Matching page currently embeds the original activity from the existing
[Bio106_Study_Resources repository](https://github.com/aemelton/Bio106_Study_Resources).
The original repository is intentionally left unchanged. The new page displays the
existing published game so its current functionality remains available during the migration.
